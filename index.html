Pattern sketch: dedupe in Apex

The same logic I run as a Deluge function in Zoho, written as an Apex trigger. Practice code, not client work.

trigger LeadDedupe on Lead (before insert) {
  Set<String> phones = new Set<String>();
  for (Lead l : Trigger.new) {
    if (l.Phone != null) phones.add(l.Phone);
  }
  Map<String, Lead> seen = new Map<String, Lead>();
  for (Lead e : [SELECT Id, Phone FROM Lead
                 WHERE Phone IN :phones]) {
    seen.put(e.Phone, e);
  }
  for (Lead l : Trigger.new) {
    if (seen.containsKey(l.Phone))
      l.addError('Duplicate lead for ' + l.Phone);
  }
}
